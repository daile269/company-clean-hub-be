Đây là thư mục chứa ảnh template mặt SAU của CCCD Việt Nam.

## Hướng dẫn đặt ảnh template:

Anh cần chuẩn bị và đặt ảnh template vào thư mục này với đặt tên như sau:

- cccd_back_v1.jpg    → Template CCCD mặt sau (phiên bản thẻ chip hiện tại)
- cccd_back_v0.jpg    → Template CCCD mặt sau (phiên bản cũ nếu cần hỗ trợ)

## Yêu cầu ảnh template:

- Ảnh CCCD mặt SAU
- Độ phân giải tối thiểu: 800x500 px
- Định dạng: JPG hoặc PNG
- Ánh sáng đồng đều, không có bóng
- CCCD chiếm phần lớn diện tích ảnh
- Không bị mờ, không bị nghiêng
- Đây là ảnh mẫu để hệ thống học layout/template, KHÔNG dùng ảnh CCCD thật có thông tin cá nhân

## Vùng đặc trưng mặt SAU (CCCD chip hiện tại):

+------------------------------------------------------+
|                                                      |
|   Đặc điểm nhận dạng:                               |
|                                                      |
|   Ngày cấp:              Nơi cấp:                   |
|   BỘ CÔNG AN                                         |
|                                                      |
|   [QR Code góc phải]     [Chữ ký CQC]               |
|                                                      |
|   MRZ Line 1                                         |
|   MRZ Line 2                                         |
|                                                      |
+------------------------------------------------------+

## Lưu ý về QR Code:

- Mặt sau CCCD chip có QR Code ở góc trái dưới (hoặc phải tùy phiên bản)
- QR Code là vùng đặc trưng QUAN TRỌNG để nhận diện mặt sau
- Trong ảnh template, QR Code không cần có nội dung thật
